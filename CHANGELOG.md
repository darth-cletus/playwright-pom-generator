# Changelog

## v0.4.0 (unreleased)

- Added an optional authenticated loopback companion for real Python Playwright locator validation over CDP.
- Added document and target correlation, match and state evidence, optional trial actions, and cancellable batch validation.
- Integrated runtime freshness, candidate recommendations, Python export policies, and JSON evidence.
- Added Python API and live Playwright tests plus an unpacked-extension companion workflow in CI.

## v0.3.0 (unreleased)

- Added interactive semantic and exact inspection, in-page highlights and tooltips, and DOM hierarchy navigation.
- Unified scanned and picked elements into one collection with stable row IDs, live references, duplicate prevention, and detached element warnings.
- Added assertion locators for static targets and collection reordering and removal.
- Added Chromium unpacked-extension tests covering selection, cleanup, regression behavior, export, and large-DOM hover timing.

## v0.2.0 (unreleased)

- Added structured locator candidates, accessibility-based strategies, configurable test ID attributes, and explainable stability and reliability scores.
- Added candidate inspection, manual overrides, and restoration of the automatic recommendation.
- Added validation provenance and blocked Python generation for choices without a unique intended match.
- Updated JSON exports to carry structured candidates and stable choice IDs.
- Added Chromium and Python Playwright integration checks alongside the existing unit tests and build.

## v0.1.0

- Introduced the Chromium side panel for discovering controls, choosing CSS and test-ID locators, highlighting, and generating synchronous Python page objects and JSON models.
