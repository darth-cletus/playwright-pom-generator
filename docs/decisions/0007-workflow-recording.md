# Record passive events and lower reviewed workflows

Interaction recording has a different contract from inspection. The inspector may suppress gestures while picking a target. The recorder uses passive capture listeners and leaves the application in control. Instrumenting application JavaScript could change its behavior, and starting the CDP companion for all captures would make local recording dependent on optional infrastructure. The content recorder instead recognizes trusted events and uses the existing browser matcher, accessible document traversal and navigation lifecycle. [DOM event contract](https://dom.spec.whatwg.org/#interface-event)

A recording port owns one document attachment and carries bounded, ordered messages. Same-origin frames and open shadow roots contribute structural frame and host boundaries. The panel controls consent, pause, stop and interruption. A new tab or inaccessible document never joins a session silently. Explicit continuation requires the original tab and origin. [Chrome extension ports](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)

The raw capture contract excludes page text, selector attribute values, form values, filenames, clipboard data and complete URLs. Captured selectors contain tag names and structural position only. Browser matching checks the candidate at capture, which does not prove future target identity. When the user associates an approved workflow with a scan, live references travel only through extension IPC and are matched against the current model. The existing candidate and user edits remain authoritative for that generated page method.

Portable workflow schema v1 stores ordered typed actions and optional user-authored parameter names. Review resets approvals on import or draft recovery. Playback is generated Python source. The extension does not replay imported or recorded actions. POM-011 can consume reviewed workflow actions, assertion kinds, and parameter references through this contract.
